DESCRIPTION
Sip Fisher is the cozy incremental game about sucking a lake up with a straw. It was a short student project with only <strong>three months development.</strong> It has grossed over <strong>$130,000</strong> in revenue since it's release in August, 2025. The game was nominated for the <strong>2026 IGF Best Student Game Award.</strong>


<i>I was brought on to this project initially as a <em>narrative designer</em> and the sole <em>market researcher</em>, focused on the game's ending and the character writing for our loveable shopkeep. Post release, I became the <em>project lead</em> for content updates and bug fixes, working with a smaller team.</i>
END DESCRIPTION
