DESCRIPTION
A small, humorous passion project developed over the course of <strong>one month</strong> for the <strong>Steam Horse Fest.</strong> The game grossed a humble <span class="extra-strong">$15,000</span> and provided pivotal learning in <strong>community building.</strong> The game was also speedran for the <strong>Galloping For The Gals</strong> charity event supporting the Malala Fund.


<i>I was a <em>content lead</em> on this project, and responsible for the <em>level design and narrative</em> for the first and last areas of the game. Additionally, I was a <em>supporting programmer</em>, building our dialogue system and other bespoke features.</i>
END DESCRIPTION
